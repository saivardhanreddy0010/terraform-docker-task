## 12. Troubleshooting - Port Conflict

During the first Terraform apply, host port `8080` was already being used.

Command:

```powershell
netstat -ano | findstr :8080
```

The port was being used by a Java process.

Command:

```powershell
tasklist | findstr 7092
```

Result:

```text
java.exe
```

Instead of stopping the Java application, the Terraform configuration was changed to use port `8081`.

After this change, Terraform apply completed successfully.
